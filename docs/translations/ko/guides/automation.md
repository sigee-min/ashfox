게임 저장소에 컴파일러 패키지와 원본을 고정합니다. OGG를 사용한다면 CI의 FFmpeg 빌드도 고정하세요. 의존성이 없을 때 관계없는 패키지를 내려받지 않도록 로컬에 설치된 실행 파일을 사용합니다.

원본 소유권, PR 검토 자료, 릴리스 운영은 [Assets as Code](assets-as-code.md)부터 확인하세요.

## 재현성과 동시 실행

원본·설정, 번들에 포함된 컴파일러, 실행 프로필이 빌드 식별자에 반영됩니다. OGG에는 인코더 지문도 추가됩니다. 같은 프로필로 깨끗한 출력 폴더에서 다시 빌드하면 번들 해시가 같아야 합니다. Node·V8·OS·아키텍처·인코더 프로필이 다르면 일치를 보장하지 않습니다.

연산 캐시나 watch 모드는 없습니다. 기존 불변 결과물도 다시 계산한 뒤 검증합니다. 파일 감시 도구나 프로젝트 빌드 시스템에서 CLI를 호출하되, 같은 출력 디렉터리에 쓰는 작업이 겹치지 않도록 하세요. 같은 위치를 대상으로 동시 빌드하면 종료 코드 4로 실패합니다.

## 배포 경계

검증된 불변 팩의 업로드나 복사는 별도 게임 빌드 단계에서 수행합니다. CLI는 서버를 배포하거나 사용자에게 설치된 게임을 수정하거나 패키지를 공개하지 않습니다. ZIP이 필요하면 `archive: true`를 선택하고, 그렇지 않으면 출력 폴더를 사용하세요. 런타임 영수증이나 생성물 대신 원본을 버전 관리합니다.
